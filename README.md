# 🚀 Featured Projects

## 🛡️ AEGIS

**Modern Windows Security & Threat Analysis Suite**

AEGIS is an independent Windows security project focused on local threat analysis, system visibility and security-oriented tooling.

### Includes

* 🛡️ Local threat analysis
* 🔬 Heuristic analysis
* 🧬 YARA-based analysis
* ☁️ VirusTotal API integration
* 🪟 Microsoft Defender integration
* ⚙️ Process monitoring
* 🌐 Network monitoring
* 🚀 Startup management
* 🔎 File & hash analysis
* 🎨 Security-focused UI

> AEGIS is a Python-based independent security project, not a kernel-level commercial antivirus.

**→ Check out AEGIS in my repositories.**
